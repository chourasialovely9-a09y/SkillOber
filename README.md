# SkillOber – AI-Powered E-Learning Platform

## Overview

SkillOber is a modern AI-powered E-Learning Platform built using React.js and Tailwind CSS.

The platform helps students:

* Discover courses
* Track learning progress
* Explore learning paths
* Interact with instructors

through a clean and responsive interface.

---

## Features

### Student Features

* Browse available courses
* Course Details Page
* Search Courses
* Student Dashboard
* Progress Tracking
* Learning Statistics

### Instructor Features

* Instructor Dashboard
* Course Management Interface
* Revenue Analytics
* Student Enrollment Tracking
* Course Performance Monitoring

### Platform Features

* Responsive Design
* Modern UI/UX
* React Router Navigation
* Reusable Components
