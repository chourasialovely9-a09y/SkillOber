# SkillOber – AI Powered E-Learning Platform

## Overview

SkillOber is a full-stack AI-powered E-Learning Platform developed as part of the Aarivya Labs Internship Program.

The platform enables students to browse courses, enroll in courses, track learning progress, and access personalized dashboards while providing instructors and administrators with management and analytics capabilities.
