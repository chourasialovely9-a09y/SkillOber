# SkillOber Frontend

Frontend application for SkillOber built using React.js, Vite, and Tailwind CSS.

## Features

* Home Page
* About Page
* Contact Page
* Login & Registration
* Courses Page
* Course Details Page
* Student Dashboard
* Learning Analytics Dashboard
* Instructor Dashboard
* Admin Dashboard
* Progress Tracking
* Performance Visualization Charts
* Responsive UI

## Tech Stack

* React.js
* Vite
* Tailwind CSS
* React Router DOM
* Axios
* Recharts

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
